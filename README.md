# Bamboo Dojo — Precision Katana Fruit Slicer

Fluid physics-based blade slicing arcade game with parabolic fruit trajectories, multi-slice combo multipliers, bomb hazard evasion, splatter canvas effects, and authentic woodblock aesthetics.

## Product Highlights
- **Domain**: Game
- **Visual Theme**: Wabi-Sabi Bamboo & Lacquer Vermillion
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
